# DevAgent Studio 前端设计

## 方向

清晰的信息层级，配合克制的交互反馈。采用 Framed sheet（seed `512731356`），未重抽方向：浅灰导航框架、白色工作区、统一细边框。橙色只用于少量品牌细节、主要操作和关键选中状态。

真实对象包括项目路径、任务目标、执行方式、工作流节点与连线、事件、人工审核、报告、知识记录、工具、技能和模型用量。工作台首先回答“这次要做什么、执行到哪一步”；编排页回答“如何执行”；报告页回答“得到了什么结论”；能力管理页回答“有哪些能力可用”。

产品标记以 DevAgent 首字母 D 为深色外轮廓，内部由一条路径分支连接两个橙色节点，表达任务分解与 Agent 协作。已移除方括号构图；导航标记和浏览器图标共用 `web/public/assets/favicon.svg`，避免两处图形不一致。品牌图形采用项目自行绘制的 SVG，不使用第三方品牌素材。沿用项目既有 Lucide 界面图标系统；Geist 字体通过依赖本地打包，中文使用系统字体。没有添加演示数据或虚构统计。

## 结构与交互

- `web/src/components/WorkbenchShell.tsx` 管理分组导航、项目上下文、任务状态、快捷搜索和移动端菜单。
- `web/src/workbench.css` 管理设计变量、框架、控件、反馈及响应式布局；`styles.css` 保留各业务组件结构，移除旧主题叠加。
- 运行页按任务配置、执行动态、任务详情组织；扫描范围和人工审核收进高级设置。报告内容统一通过标签切换，移除重复报告区。
- 执行方式的选中块使用 transform 平移；按钮轻微按压；对话框减速进入。系统要求减少动态效果时停用这些动画。
- Ctrl / Command + K 搜索页面，方向键选择，Enter 打开，Escape 关闭并恢复焦点。原生 dialog 提供焦点约束；移动端菜单用同一套导航数据。
- 原有运行、审核、编排、知识库、模型、工具和插件 API 保持不变。

## 验证

生产构建使用 `npm run build`。浏览器验证覆盖 1440、768、390 像素下的全部 10 个页面，以及搜索、键盘、移动导航、模式与场景切换、高级设置、SSE 事件、节点详情、失败后的重试状态和减少动态效果设置。任务执行验证使用拦截响应，不发起真实模型调用。

视觉检查的 12px 辅助文字提示保留：正文、输入和导航为 14px，路径说明、提示、状态、日志元信息为 12px；较长 JSON 和日志采用等宽字体。工作流画布保留点阵用于定位节点，对话框保留模糊背景用于区分模态层。

本地截图和检查结果位于忽略版本控制的 `web/.taste-skill/`。
